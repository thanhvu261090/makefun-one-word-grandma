The single word grandma would text about AI.

> "robut"

Grandma means "robot", but her fingers land one key off — so it comes out "robut". Warm, a little baffled, funny in one word, and unmistakably about the machine.

## How it works

`main.py` holds the entry word as a constant, checks it against the kit's gate (UTF-8 text, 1–30 characters, not only whitespace, exactly one word, no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
